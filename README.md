# Brew & Bean ☕

A modern, responsive landing page for a fictional specialty coffee shop.

## ✨ Features

* Responsive design for desktop, tablet and mobile
* Interactive mobile navigation
* Menu filtering by category
* Interactive order counter
* Smooth scrolling navigation
* Scroll reveal animations
* Custom SVG illustrations
* Dark mode support based on system preferences
* Accessible navigation and controls

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* SVG
* Google Fonts

## 📱 Responsive Design

The website is designed to work across different screen sizes, from desktop displays to mobile devices.

## 🎯 Purpose

This project was created as a frontend portfolio project to demonstrate responsive web design, CSS styling, JavaScript interactivity, and attention to UI/UX details.
